# SFFT Veil Kings III

WordPress plugin. Version 3.4.0, The War of Masks.

## Download

The installable zip is on the Releases page:

https://github.com/duanecol74-creator/sfft-veil-kings-iii/releases/latest

Direct file:

https://github.com/duanecol74-creator/sfft-veil-kings-iii/releases/download/v3.4.0/sfft-veil-kings-iii-3.4.0-wordpress.zip

## Install

1. Download the zip.
2. WordPress → Plugins → Add New → Upload Plugin.
3. Activate SFFT Veil Kings III.
4. Put this on a page: `[sfft_veil_kings_iii]`
